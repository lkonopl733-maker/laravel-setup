Лабораторна робота №4: Кешування у Web

Перелік реалізованих механізмів кешування:

  • Клієнтське кешування (Приклад 1 — CSS): Файл стилів client-asset.php віддається із заголовком Cache-Control: public, max-age=86400.
  • Клієнтське кешування (Приклад 2 — Зображення):
    Зображення вище (client-image.php) кешується браузером на 2 дні. Перевірте вкладку Network → Size має показувати (from disk cache) або (memory cache).
  • Серверне файлове кешування: Відкрити звіт (generate-report.php) — генерація 1000 рядків таблиці із затримкою sleep(3) та збереженням у файл на 10 хвилин.
  • Серверне кешування через сесію: Відкрити курс валют (session-cache.php) — збереження даних у $_SESSION з обмеженням часу.
  • Серверне кешування через статичну властивість класу: Відкрити клас-кеш (class-cache.php) — збереження у пам'яті за допомогою статичної властивості.
